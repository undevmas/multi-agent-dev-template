# Entregables/

Documentos formales y sus evidencias, por proyecto. Lo que se genera aquí **no se versiona** en el
repositorio de la plantilla ni en el repositorio de código del proyecto (`.gitignore` solo conserva
este README): contiene capturas y documentos de sistemas reales.

```
Entregables/<Proyecto>/
├── evidencias/
│   ├── diagramas/<id>/   candidate.json · <id>.html · <id>.png · <id>.json
│   └── capturas/<modulo>/<NN-paso>.png · <NN-paso>.json
├── memoria-tecnica/      memoria-tecnica.md → Memoria_Tecnica_<Sistema>_v<ver>.docx
├── manual-usuario/       manual-usuario.md  → Manual_de_Usuario_<Sistema>_v<ver>.docx
└── auditoria-preprod/<YYYYMMDD_HHmm>/   hallazgos-preprod.md · hallazgos-preprod.html
```
